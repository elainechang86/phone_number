# 台灣手機號碼隨機產生器

GitHub Pages 可直接使用的靜態網頁工具。

## 功能

- 依照指定的台灣電信門號區塊隨機產生 10 碼手機號碼
- 預設一次產生 100 筆
- 可選擇全部電信或指定電信
- 同一瀏覽器中，歷史產生過的完整號碼不會再次產生
- 一鍵複製全部
- 下載 CSV
- 生成歷史紀錄：記錄每次生成的時間、範圍與全部號碼
- 可展開查看每次生成結果並單獨複製
- 可下載完整生成歷史 CSV
- RWD 手機版介面
- 不需要後端或資料庫

## GitHub Pages

1. 建立一個 GitHub repository。
2. 上傳 `index.html`。
3. Repository → Settings → Pages。
4. Source 選 `Deploy from a branch`。
5. 選 `main` / `root` 後儲存。
6. 等待 GitHub Pages 部署完成即可。

## 注意

去重紀錄使用瀏覽器 Local Storage，因此資料只存在使用者目前的瀏覽器。
如果換電腦、換瀏覽器或清除網站資料，歷史紀錄不會保留。

本工具只依照提供的門號區塊產生「格式符合」的號碼，不代表該號碼實際已由電信業者配發或目前可使用。
